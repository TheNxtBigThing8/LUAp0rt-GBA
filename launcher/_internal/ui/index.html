How this works: tick the games to include. When you press Launch, the checked games are sent to the console first, then LUAp0rt starts. A game is skipped automatically if this launcher already sent that exact file, or the console reported it present with the same size in this session, so nothing is uploaded twice. Unselected games are simply left alone. Send selected ROMs does the sending without launching; Clear selected ROMs removes the selected games from the console (it asks first, your PC copies stay, and it deselects them so they are not sent back). The box in the table header selects every row.

Files that do not end in .gba (any case) are ignored. "On console" comes only from the console itself: a check through the Lua loader (Rescan, and automatically after every send) or its own /temp0 report when the emulator starts. Only within this session.

GBA BIOS

Goes to /temp0/gba_bios.bin with the next launch if the console does not have it yet.
Any region's BIOS is accepted: only the size is checked (exactly 16,384 bytes, a GBA requirement); LUAp0rt ships no BIOS and will not help you obtain one. Supply only firmware you are legally entitled to use.

Launch

Payload
  1. PS5 address set
  2. Payload pair present and hash-verified
  3. Lua loader listening on TCP 9026
  4. BIOS and ROMs are on the console in /temp0
Sends m16cgpsp.lua to TCP 9026, then streams m16cgpsp.bin to the first ACKing port in 9028–9045, via the unmodified tools/send.py.
