PROVENANCE OF THIS FILE
-----------------------
libretro-common does not ship a single top-level LICENSE file in the frozen
gpSP tree. Instead, each file carries its own license statement in its header,
and each statement is scoped to that file by its own wording ("The following
license statement only applies to this file (<name>)").

The notices below are reproduced VERBATIM from the frozen source snapshot. They
have not been rewritten, summarised, merged or reformatted. Where two files
carry the same notice, both are reproduced so that the per-file scoping wording
is preserved exactly as found.

The libretro-common headers reached by the LUAp0rt GBA v0.0.1 shipping build are
included in the corresponding-source scope; see THIRD_PARTY_NOTICES.md §3.
